# 偏好与策略

当用户给出偏好、询问策略差异，或上次结果暴露“中性其实会失望”时，读取本文件。

## 先分档，再选策略

评分采用 `-10` 至 `+10` 的七档默认规则：

| 分值 | 档位 | 默认用途 |
|---|---|---|
| `+10` | 最爱 | 计入喜欢目标，且排在普通喜欢之前 |
| `+6` 至 `+9` | 喜欢 | 计入喜欢目标 |
| `+1` 至 `+5` | 可接受 | 不计入喜欢或不喜欢 |
| `0` | 中性 | 不计入喜欢或不喜欢 |
| `-1` 至 `-4` | 中性但失望 | 不计入不喜欢风险 |
| `-5` 至 `-8` | 轻雷 | 计入不喜欢风险 |
| `-9` 至 `-10` | 硬雷 | 计入不喜欢风险和硬雷风险 |

只给 `scores` 时，求解器按上表自动生成完整七档，并推导
`liked`、`disliked`、`hard_avoid`。`score_default` 补齐的分数也参与分档。
用户明确提供任一对应字段时，以该字段为准；显式空数组也覆盖自动推导。
硬雷概率上限不会从分数推断，仍需用户明确提供。

排序只能表达先后，不能表达差距。临界决策优先让用户逐款打分；未列款可统一为 `0` 分。

## 六种策略

| 策略 | 选择规则 | 适合 |
|---|---|---|
| 稳妥避雷 | 先压低排序靠前的不喜欢款风险，再比较其余风险和喜欢率 | 不想打分，只想尽量别踩雷 |
| 守住底线 | 硬雷概率不过上限才有资格；合格盒中选平均评分最高 | 硬雷绝不能太高，同时想兼顾喜欢与失望 |
| 整体最满意 | 直接选平均评分最高；高分款可以补偿低分款风险 | 接受权衡，目标是长期平均体验最好 |
| 随便中个喜欢 | 选“任一喜欢款”概率最高 | 喜欢款彼此差距不大，中一个就开心 |
| 只冲最爱 | 先选第一喜欢款概率最高，再比较第二喜欢款 | 其他款无法替代最爱 |
| 保值优先 | 选预期二手价值最高 | 抽到非自留款会出售 |

默认使用 `稳妥避雷`。只有逐款评分包含硬雷档位（或用户另行明确硬雷）且给出上限时，才使用 `守住底线`；给出逐款评分且接受补偿时，使用 `整体最满意`。

## 用户输入

自然语言输入即可：

```text
策略：守住底线
硬雷：把我吃掉
轻雷：别靠近我、抓到你了、捡到幸运
中性但失望：出逃计划
硬雷上限：15%

评分：
雨中远航 +10
不想睡觉 +8
灵魂交互 +7
在你身后 +6
出逃计划 -2
把我吃掉 -10
别靠近我 -6
抓到你了 -6
捡到幸运 -5
其余 0

停止条件：
喜欢款至少 55%
最爱款至少 15%
不喜欢款不超过 30%
最多抽 2 盒
```

分数只表示个人满意度，不必等距；同一轮保持同一量尺即可。`-9` 至 `-10`
默认推导硬雷身份，但硬雷概率上限仍是独立约束。

## 机器字段

将自然语言转成。下例省略 `liked`、`disliked`、`hard_avoid`，由评分默认推导：

```json
{
  "strategy": "守住底线",
  "scores": {
    "雨中远航": 10,
    "不想睡觉": 8,
    "灵魂交互": 7,
    "在你身后": 6,
    "出逃计划": -2,
    "把我吃掉": -10,
    "别靠近我": -6,
    "抓到你了": -6,
    "捡到幸运": -5
  },
  "score_default": 0,
  "hard_avoid_max_pp": 15,
  "stop_rules": {
    "min_like_any_pp": 55,
    "min_favorite_any_pp": 15,
    "max_dislike_any_pp": 30,
    "max_draws": 2
  }
}
```

`min_favorite_any_pp` 检查所有 `+10` 最爱款的合计概率，且要求评分中
至少存在一个 `+10` 款。它与喜欢款停止线独立：任一未达标就停止，但不
改变原策略的选盒排序；若要优先选择最爱概率最高的盒，改用 `只冲最爱`。

停止条件是“任一不满足就停”。每次提示、显示或开盒后，重新检查当前最佳盒。
