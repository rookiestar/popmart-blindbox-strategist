# 偏好与策略

当用户给出偏好、询问策略差异，或上次结果暴露“中性其实会失望”时，读取本文件。

## 评分先行，自动分档

评分采用 `-10` 至 `+10` 的七档默认规则：

| 分值 | 档位 | 默认用途 |
|---|---|---|
| `+10` | 最爱 | 计入喜欢目标，且排在普通喜欢之前 |
| `+6` 至 `+9` | 喜欢 | 计入喜欢目标 |
| `+1` 至 `+5` | 可接受 | 不计入喜欢或不喜欢 |
| `0` | 中性 | 不计入喜欢或不喜欢 |
| `-1` 至 `-4` | 中性但失望 | 不计入不喜欢风险 |
| `-5` 至 `-8` | 轻雷 | 计入不喜欢风险 |
| `-9` 至 `-10` | 硬雷 | 计入不喜欢风险和硬雷风险 |

新会话优先让用户给每个常规款打分。求解器按上表生成完整七档，并推导
`liked`、`disliked`、`hard_avoid`，无需再让用户重复列类别。

`score_default` 只在用户明确同意“其余款同分”后使用，并同时写入
`score_default_confirmed: true`。理想输入仍是逐款完整评分。用户明确提供
`liked`、`disliked` 或 `hard_avoid` 时，对应字段继续覆盖自动推导；
显式空数组也覆盖自动推导，以兼容旧状态。
新的 `只冲最爱` 校准应省略显式 `liked`，让所有同分最爱按合计概率处理；
显式顺序仅保留给旧式逐款目标流程。

分数决定款式属于哪一档，不决定用户应接受多高概率。喜欢下限、不喜欢上限
和硬雷上限必须结合当前端真实可达值校准，再由用户确认。

## 六种策略

| 策略 | 选择规则 | 适合 |
|---|---|---|
| 稳妥避雷 | 先压低排序靠前的不喜欢款风险，再比较其余风险和喜欢率 | 希望评分自动识别雷区，核心是尽量别踩雷 |
| 守住底线 | 硬雷概率不过上限才有资格；合格盒中选平均评分最高 | 硬雷绝不能太高，同时想兼顾喜欢与失望 |
| 整体最满意 | 直接选平均评分最高；高分款可以补偿低分款风险 | 接受权衡，目标是长期平均体验最好 |
| 随便中个喜欢 | 选“任一喜欢款”概率最高 | 喜欢款彼此差距不大，中一个就开心 |
| 只冲最爱 | 评分输入先最大化所有最高分款合计；显式喜欢顺序仍按逐款比较 | 其他款无法替代最爱 |
| 保值优先 | 先看预期二手价值；个人评分、总雷和硬雷作为确认约束 | 抽到非自留款会出售 |

没有评分和明确目标时默认使用 `稳妥避雷`。只有逐款评分包含硬雷档位
（或用户另行明确硬雷）且确认上限后，才使用 `守住底线`；给出逐款评分且
接受补偿时，使用 `整体最满意`。

## 新会话校准流程

1. A–E 五个主目标都收集每款 `-10` 至 `+10` 评分、卡片数和最多抽盒数。
   E 还要收集当前、同口径、覆盖全部常规款的 CNY 市场价值。
2. 此时只保留抽盒预算，不要求用户猜概率线。
3. 在当前端运行：

```bash
python3 scripts/blindbox_solver.py <state.json> \
  --calibrate-preferences --format markdown
```

4. 原样展示自动分档、全部可选盒指标、真实可达区间和未被其他盒全面压过的
   取舍。对于
   `只冲最爱`，主指标是 `p_favorite_any`，风险校准指标是
   `p_dislike_any` 与 `p_hard_avoid`。
   对于 `保值优先`，主指标是 `resale_ev`，同时校准
   `expected_score`、`p_dislike_any` 与 `p_hard_avoid`。
   这些是当前直接可选盒的指标；卡片在边界确认后另行规划。
5. 报告最多给三种透明取向：最爱/目标优先、硬雷最低、总雷最低。候选线
   向“参考盒仍可通过”的方向取整，但仍只是建议。
6. 用户回复方案1/2/3或修改数字，才把该组边界写入 `stop_rules` 并生成正式
   抽盒报告。选择方案即表示确认该组本轮边界；多端会话同时记录对应
   `stop_rule_override`。

校准依据来自当前端；确认后的边界可用于同系列当前会话及后续换端。换系列或
评分实质变化时重新校准。每条新提示只需按已确认边界全局重算，不因一次结果
改写评分或门槛。

## 用户输入

自然语言只需给评分和预算，不再预估概率：

```text
策略：只冲最爱

评分：
雨中远航 +10
不想睡觉 +10
灵魂交互 +7
在你身后 +4
出逃计划 -3
把我吃掉 -10
别靠近我 -8
抓到你了 -8
捡到幸运 -8
其余款 0

预算：
提示卡 6 张
最多抽 2 盒
```

若“其余款 0”确实是用户明确输入，可转成 `score_default: 0` 和
`score_default_confirmed: true`。分数只表示个人满意度，不必等距；同一轮
保持同一量尺即可。

## 校准前机器字段

下例省略 `liked`、`disliked`、`hard_avoid`，由评分自动推导。除已确认的
`max_draws` 外，不先写概率停止线：

```json
{
  "strategy": "只冲最爱",
  "scores": {
    "雨中远航": 10,
    "不想睡觉": 10,
    "灵魂交互": 7,
    "在你身后": 4,
    "出逃计划": -3,
    "把我吃掉": -10,
    "别靠近我": -8,
    "抓到你了": -8,
    "捡到幸运": -8
  },
  "score_default": 0,
  "score_default_confirmed": true,
  "stop_rules": {
    "max_draws": 2
  }
}
```

用户确认候选后，才增加 `min_favorite_any_pp`、
`max_dislike_any_pp`、`max_hard_avoid_pp` 等质量线。每个已配置条件都必须
通过。`min_favorite_any_pp` 检查所有 `+10` 最爱款的合计概率；在评分派生
的 `只冲最爱` 中，同一批 `+10` 款也是首要排序目标。

停止条件是“任一不满足就停”。每次提示、显示或开盒后，重新检查当前最佳盒。
