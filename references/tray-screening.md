# 限时端筛选

用户先进入泡泡玛特在线抽盒机的一端，默认摇盒后通常只有 3–5 分钟。
本流程先判断当前端是否值得占住，再进入完整选盒与道具规划。

## 判断边界

“理想端型”不是固定的提示条数。相同数量的“不是”，因排除款式和全盘
约束不同，价值可能完全不同。以当前最佳盒的联合后验指标检查用户设置的
质量入场线：

- `min_like_any_pp`
- `min_favorite_any_pp`
- `max_dislike_any_pp`
- `max_hard_avoid_pp`
- `min_expected_score`
- `守住底线`的 `hard_avoid_max_pp`

`max_draws` 是整轮上限，不是端质量。只有 `max_draws` 时不能判断端型，
应先补至少一条质量入场线。没有默认摇盒状态的真实分布时，也不能计算
“下一端一定更好”或理论最优换端次数。

## 快速命令

```bash
python3 scripts/blindbox_solver.py <state.json> \
  --screen-tray --digits 10
```

`--screen-tray`固定使用一步规划。决定保留当前端后，才按需运行较慢的
`--plan-depth 2`。

## 状态与动作

| `tray_screening.status` | 含义 | 默认动作 |
|---|---|---|
| `ready` | 当前最佳盒直接通过全部质量入场线 | 保留此端，执行当前最优动作 |
| `tool_dependent` | 直接未达线，但一步道具有非零概率产生可抽分支 | 仅在愿意消耗该卡时保留，并显示达线概率 |
| `switch` | 直接未达线，且一步规划仍选择停止 | 不用卡，换端 |
| `session_stop` | 已达到整轮抽盒上限 | 停止整轮；换端无效 |
| `needs_acceptance_rules` | 没有质量入场线 | 先根据偏好补入场线，不宣称端型好坏 |

`tool_dependent`不是直接合格。报告
`one_card_action.expected_draw_probability`，不要把“存在可救分支”写成高
成功率，也不要因卡片免费或已持有就忽略其稀缺性。

## 下一端入场线

下一端默认摇盒后，只要当前最佳盒的 `acceptance_profile` 全部通过，就可
开始尝试。报告每条规则的实际值、门槛和 `margin`；负数是还差多少。
不要把某个盒“至少出现 N 条提示”当成跨端门槛。

若用户连续发送多个端：

1. 每端独立建模，不合并盒号、排除或已售状态。
2. 保留上一端的指标摘要用于复盘，但已释放的端不再列为可选项。
3. 两端仍同时可占用时，才在同一策略和入场线下直接比较。

## 限时回复

端筛选回复只给：

- `直接可做 / 依赖道具 / 建议换端 / 本轮停止 / 需先设入场线`；
- 当前最佳盒及未达线差值；
- 若依赖道具，首张卡、目标盒和用卡后仍可抽的概率；
- 下一端的质量入场线；
- `隐藏款：默认未计入`。

筛选阶段省略完整 TOP 3 分布。用户保留当前端后，再输出完整选盒报告；
不要在同一倒计时内重复市场研究。
